## О проекте

Выпускная квалификационная работа на тему «Тренажёр автоматической коррекции акцентуализированной речи». Система разработана в рамках магистерской диссертации. **ИМКТ ДВФУ, 2026 год**.

Тренажёр предназначен для автоматизированного анализа произношения пользователя, выявления акцентных отклонений и формирования персонализированного маршрута обучения с учётом специфики фонетической интерференции русского языка при освоении английского.

### Решаемые задачи

1. Автоматическая оценка качества произношения пользователя.
2. Идентификация акцентных отклонений с учётом родного языка.
3. Формирование индивидуальной программы обучения.
4. Хранение и отслеживание прогресса пользователя.
5. Обеспечение обратной связи в реальном времени.


## Возможности

- **Запись и загрузка аудио** — пользователь записывает речь через браузер или загружает готовый файл.
- **Автоматическая сегментация речи** на фонемы методом форсированного выравнивания.
- **Извлечение акустических признаков** — мел-частотных кепстральных коэффициентов (MFCC) с их производными первого и второго порядка.
- **Сравнение с эталоном** через динамическую трансформацию времени (DTW).
- **Критерий акцентуализированности** — статистический порог $\mu_j + 2\sigma_j$ для каждой фонемы.
- **Балльная оценка произношения** в шкале 0–100.
- **Персонализированный курс упражнений** на основе выявленных слабых фонем.
- **История попыток и динамика прогресса** пользователя.
- **Админ-панель** для управления эталонными образцами и просмотра статистики.
- **Контроль качества записи** через отношение сигнал/шум (SNR).

## Архитектура 
Система построена по трёхслойной архитектуре

```bash
┌─────────────────────────────────────────────────┐
│   Презентационный слой (Jinja2 + HTML/CSS/JS)   │
├─────────────────────────────────────────────────┤
│   Прикладной слой (FastAPI, REST API)           │
├─────────────────────────────────────────────────┤
│   Слой обработки речи (librosa, DTW, MFCC)      │
├─────────────────────────────────────────────────┤
│   Слой данных (SQLAlchemy + SQLite)             │
```

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/theApsil/accent-analyzer.git
cd accent-analyzer
```
## 2. Установка ffmpeg
Windows:
```bash
winget install ffmpeg
```

macOS:
```bash
brew install ffmpeg
```
Linux (Ubuntu/Debian):
```bash
sudo apt install ffmpeg
```


## 3. Установка uv
```bash
pip install uv
```
Или через официальный установщик:

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```
## 4. Создание виртуального окружения и установка зависимостей
```bash
uv sync
```
Эта команда автоматически:

- создаст виртуальное окружение в папке .venv;
- установит все зависимости из pyproject.toml;
- создаст файл блокировки версий uv.lock.

## 5. Инициализация базы данных
```bash
uv run python -m app.init_db
```
Команда создаст:

- файл базы данных data/accent_analyzer.db;
- необходимые таблицы;
- тестовые аккаунты user и admin;
- набор демонстрационных эталонных образцов.
## 6. Запуск приложения
```bash
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
> Приложение будет доступно по адресу: http://localhost:8000

## Использование
### Сценарий обычного пользователя
1. Войдите в систему по адресу `http://localhost:8000/login` с учётной записью `user` / `user`.
2. Пройдите калибровку — система запросит несколько фраз для адаптации к вашему голосу и определения базового уровня.
3. Получите дашборд с рекомендованными упражнениями, разбитыми по сложности (easy/medium/hard) и целевым фонемам.
4. Запишите попытку на странице загрузки: можно записать через микрофон или загрузить готовый WAV/MP3.
5. Получите результат — балл произношения 0–100, выделенные акцентуализированные фонемы и текстовые рекомендации.
6. Отслеживайте прогресс в истории попыток.
### Сценарий администратора
1. Войдите с учётной записью `admin` / `admin`.
2. Получите доступ к админ-панели с обзором всех пользователей и их попыток.
3. Загружайте новые эталонные образцы для расширения базы.
4. Просматривайте статистику использования системы.
